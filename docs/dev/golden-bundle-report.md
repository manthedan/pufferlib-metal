## Owner-reviewed sanitization

The owner resolved the previous blocker: the 28 wide capture logs serve only
as provenance and SHA inventory inputs. The public bundle ships sanitized
copies. The only allowed rule is a regex byte replacement in
`wide_reports/*.log`: the checkout shape recorded in
[`golden_sanitization.json`](../../tests/metal/golden_sanitization.json) becomes
`<cuda-ref>/`. No other home-path, username or email redaction is allowed.
Any other actionable personal-data hit in included UTF-8 text stops packaging,
even when that text is not checksum-covered.

There are **276 replacements in 28 logs**, across the four tags `wide_a`,
`wide_b`, `wide_bf16`, and `wide_bf16_b`. For each tag the seven rewritten
suffixes are `-freeway-policy.log`, `-freeway-replay.log`, `-freeway-train.log`,
`-ops.log`, `-tetris-policy.log`, `-tetris-replay.log`, and `-tetris-train.log`.
The source's 552 real scan matches are the checkout prefix and username on
those 276 lines. After sanitization, only **4 SHA256 substring false positives**
remain, with zero actionable hits.

The packager patches the **28 corresponding digest values in
`wide_reports/SHA256.json`**, preserving every other entry, order and byte of
formatting. `wide_reports/inventory.json` contains only tensor/manifest hashes,
no log entries, so its bytes and SHA256 remain unchanged:
`bfacda491a5075f42775b57b11e706fd96a5dd1f00c59019f4196974fa6f6cfa`.
Thus **29 files change in total**. The tracked provenance records original and
sanitized SHA256 and the applied rule for all 29 files. The public fixture
contract pins all 28 sanitized logs, the regenerated SHA inventory, and the
unchanged tensor inventory. Original log and inventory hashes are verified
before packaging; generated bytes must match both provenance and public pins.

## Installation and one-time migration

The fetcher verifies archive size/digest before restricted extraction, validates
all public contracts and wide SHA entries, and installs by sibling rename.
Existing private directories fail the updated wide-report contract. The
one-time migration is:

```sh
tools/metal/fetch_goldens.sh --file /path/to/metal-goldens-v1.tar.gz \
  --destination /path/to/golden --force
```

`--force` moves the entire previous directory to a unique
`golden.backup-<unique-id>` sibling; it never deletes it. Failed validation
leaves the old directory untouched. This behavior already existed in
`cd13c15b`; the new host test demonstrates migration from the private log
contract to the public contract and verifies preservation of original bytes.
The real private capture was **not migrated**.

The public bundle excludes `protein/curand_sobol32.bin`. The exact-cuRAND
Protein gates therefore skip; the public Protein gate still runs. Private
regeneration instructions remain linked from the test README to
`tests/metal_ref/README-protein.md`.
