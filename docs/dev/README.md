# Development records

These are the working notes from building the Metal backend: optimization
relay reports (`optimization/`), parity and learning investigations
(`investigations/`), and cleanup reports. They are kept for provenance and
are not user documentation; start with the top-level README and the Metal
guide instead.

Commit hashes cited in these files refer to the private development history.
This repository publishes that work as a single commit on top of upstream
PufferLib 5.0 (`ea7f9893`), so those hashes do not resolve here.
