# Joe--Kuo Sobol direction-number excerpt

`new-joe-kuo-6.20000` is an exact byte prefix of the publisher's
`new-joe-kuo-6.21201`: its header followed by rows for dimensions 2 through
20,000, the complete range used by Protein. The generator verifies both the
full publisher file and this excerpt by SHA256 before use. See `LICENSE` in
this directory for Frances Y. Kuo and Stephen Joe's BSD-style license.
